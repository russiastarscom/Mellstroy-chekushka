КАК ЗАМЕНИТЬ СПРАЙТЫ
--------------------
Просто положи свои PNG в папку image/ с этими именами
(игра сама их подхватит; если файла нет — рисуется встроенная
заглушка):

  andrey.png         — Андрей (смотрит ВПРАВО)
  burmaldenets.png   — бурмалденец-пехотинец (смотрит ВЛЕВО)
  boss.png           — вождь-босс (смотрит ВЛЕВО)
  checkushka.png     — бутылка чекушки (коллектируемая)
  factory.png        — завод (выход с карты)
  tomahawk.png       — летящий томагавк
  heart.png          — сердечко (аптечка)
  plush.png          — плюшка (снаряд: подбирай на карте босса — стреляй)

  bg_fields.png      — фон карты 1 (поля)
  bg_city.png        — фон карты 2 (улицы)
  bg_district.png    — фон карты 3 (заводской район)
  bg_plant.png       — фон карты 4 (главный завод)

  icon-192.png / icon-512.png / icon-512-maskable.png — иконки PWA

Размеры советуем соблюдать пропорционально заглушкам.
Если файл битый/отсутствует — игра не упадёт, включится заглушка.

СОЦСЕТИ ДЛЯ ФИНАЛЬНОГО ЭКРАНА
-----------------------------
Файл js/config.js → CONFIG.SOCIALS → впиши свои ссылки
(после правок перенеси их и в index.html — там игра лежит
целиком в одном файле, см. ниже).

ЗАПУСК
------
Вариант 1: просто открой index.html в браузере — он АВТОНОМНЫЙ,
все стили и скрипты встроены прямо в него. Можно залить на хостинг
ОДИН этот файл и игра заработает.
Вариант 2 (полноценный PWA + свои спрайты): залей ВСЮ папку на любой
хостинг по HTTPS (GitHub Pages / Netlify / Vercel) — появятся
оффлайн-режим, установка на телефон и спрайты из image/.

ВАЖНО ПРО index.html
--------------------
index.html — собранная автономная версия (css/ и js/ внутри).
Исходник с раздельными файлами — index.src.html. После правок
js/*.js или css/*.css нужно пересобрать index.html, иначе игра
не увидит изменений.

УПРАВЛЕНИЕ
----------
← → / A D  — идти;  ПРОБЕЛ / W / ↑ — прыжок;  ↓+прыжок — вниз с платформы
X / кнопка ✸ — бросить плюшку (если есть боезапас)
P / ESC — пауза.  На телефоне — экранные кнопки.

ПЛЮШКИ
------
На карте Главного завода валяются розовые плюшевые горы — подбирай
(каждая даёт 3 броска) и закидывай вождя плюшками (клавиша X или
кнопка ✸ на телефоне). Плюшки также убивают рядовых бурмалденцев.

УРОВНИ
------
1. Вступление (катсцена)
2. Карта 1 — Поля Буримовки
3. Карта 2 — Улицы Буримовки
4. Карта 3 — Заводской район
5. Карта 4 — Главный завод (БОООСС) + финал «Продолжение следует»
6. В разработке...

Прогресс сохраняется в браузере (localStorage).

Фанатская треш-игра. Все совпадения с твоей бутылкой случайны.
