📦 Как выложить изменения на GitHub

  1. Нажми «⬇ Экспорт» — скачается файл game-cms.json со всеми твоими правками (карты, разговоры, текстуры, музыка, каналы, тряска).
  2. Открой репозиторий игры на GitHub: github.com/russiastarscom/Mellstroy-chekushka
  3. Ветку выбери gh-pages (именно там живёт сайт игры), папка public/game не нужна — файл кладётся в корень рядом с index.html.
  4. Нажми Add file → Upload files, перетащи game-cms.json и нажми Commit changes.
  5. Через минуту обнови игру — GitHub Pages сам отдаст файл, и ВСЕ игроки увидят правки. Публиковать на сервере для этого не нужно.
💡 Обратно в панель: «⬆ Импорт» читает game-cms.json и загружает его в редактор — можно продолжить правки с другого устройства.
💡 Тексты игры (все диалоги) лежат одним файлом js/dialogs.js — его тоже можно переписать с помощью ИИ и так же залить в папку js/ в ветке gh-pages.
